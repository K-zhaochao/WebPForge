04 / GOOD TO KNOW.

你可能想知道。

聊聊你的问题
手机安装的是 APK / App Store 原生版吗？

目前是可安装的网页应用（PWA），不是 APK 或 App Store 原生应用。Android 在浏览器菜单中安装；iPhone / iPad 用 Safari 的「分享 → 添加到主屏幕」。安装后有独立图标和窗口，资源缓存完成后可离线转换，功能与在线版一致。批量、无损和动画转换请使用桌面版。

我的图片会被上传吗？

不会。桌面版完全离线；在线版和手机轻应用也只在你的设备上处理图片。离线缓存只保存网页和公开示例，不保存你选择的图片或转换结果。关闭或更新应用前请下载结果。

转换成 WebP，会损失画质吗？

有损模式会在体积和细节之间做取舍，75–85 是多数网页图片的实用起点。对画质有严格要求，可以在桌面版开启无损模式。质量 100 的有损编码不等于无损；不同图片的压缩效果也会不同。

透明背景和 GIF 动画还能保留吗？

可以。桌面版转为 WebP 时支持透明通道，也支持 GIF 转动态 WebP。本页体验区仅处理静态图片；遇到 GIF、动态 PNG 或动态 WebP，请使用桌面版保留动画。

为什么有些图片转换后反而更大？

如果原图本身已充分压缩，或者选择了很高的画质，WebP 不一定更小。桌面版的智能模式会跳过体积没有减小的结果；在线体验会如实显示大小变化，你可以尝试降低画质。

下载后怎么用？需要安装 Python 吗？

不需要。下载对应系统的 ZIP，解压后打开 WebPForge.exe 或 WebPForge.app 即可。当前应用尚未签名，首次打开可能出现系统提示；请确认文件来自本项目的 GitHub Release，并参考 下载与启动说明。

可以免费商用吗？

可以。WebPForge 以 MIT 协议开源，可用于个人与商业项目。修改或分发软件时请保留版权与许可声明。阅读完整许可。
